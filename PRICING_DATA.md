# Pricing Assumptions

The MVP uses simplified static pricing assumptions for deterministic audit consistency.

The pricing data is intentionally approximate and should not be interpreted as real-time vendor pricing.

## Why Static Pricing?

The project intentionally avoids:
- vendor scraping
- unstable pricing APIs
- region-specific billing logic

The goal of the MVP is optimization modeling rather than accounting-grade accuracy.
